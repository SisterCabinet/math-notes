# 第4—6章整理：范围与筛选标准

本轮起点按用户明确的10月25日安排，11月14日考试，每天6—8小时。第三章已学完，转入间隔复习；既往题目的独立完成情况仍以本人实际记录为准。本稿完成教材结构与范围核对，尚未逐题定级、锁定题号日程或修改学习网页。

## 2. 逐题筛选标准

先列方法覆盖表，再给具体题定级。筛选同时看基础地位、考纲相关性、方法迁移、条件判断和实际推理长度；不因真题少见就删知识点，也不按章节平均保留比例。

- **例题A：重点掌握。** 能识别触发条件，复现核心推导并检查解的条件；必要时按小问分层。
- **例题B：保留核心方法。** 方法必须学；原题过难时配简单铺垫或初赛难度示例，再给原题关键路线。明确哪些长计算不要求首轮独立熟练，不能只写“了解”。
- **例题C：同类选学。** 指明由哪道必学题覆盖方法，保留补弱用途。
- **例题D：暂缓完整原题。** 给出特殊性、重复性或先修依赖等具体原因，同时说明通用方法在哪里保留。
- **课后K：核心必做。** 核心方法需要有独立落地题，兼顾计算、证明、建模与条件检查。
- **课后J：巩固储备。** 留出有差异的变式，按错误补练，不为凑数量添加同质题。
- **课后T：综合挑战。** 保留有迁移价值的复杂方法，写清必须理解的路线和可暂缓的长推算。
- **课后R/Z：复现备用或暂缓。** 与例题重复、共享关键解答或已看过答案的明确标注，不累计为新的未见题。

题量不预先规定百分比。先确保重要方法有对应训练，再估算核心用时。核心过重时优先削减重复变式和长计算，必要时调整日期，不通过删掉重要方法来凑天数。

## 3. 三章的考试着力点与基础补充

| 章 | 解题着力点 | 必须补清的概念与条件 | 重要复杂方法的处理 |
|---|---|---|---|
| 第4章 | 识别方程类型、选择变换、完成积分；由函数关系或几何条件建立方程 | “齐次一阶方程”与“齐次线性方程”含义不同；通解与特解；分离或代换除以函数时检查被遗漏的解；解所在区间；初始条件是否足够 | Bernoulli、全微分/积分因子、降阶、线性解的结构、共振与Euler方程逐项核对，不一概按难题暂缓；先保留可识别、可迁移的操作 |
| 第5章 | 几何条件转向量、再转方程；选择方向向量/法向量，避免无目的联立 | 数量积与向量积的输出和用途不同；平行与共线/包含的区别；线面夹角与法向量夹角；标量投影与向量投影；空间曲线与投影方程的区别 | 平面束、向量投影、辅助平面、公垂线、旋转曲面等保留方法；复杂纯几何构造与重复坐标运算按代表性取舍 |
| 第6章 | 概念判断、链式求导、隐函数与高阶偏导；切平面、梯度、无条件和条件极值的综合 | 沿若干路径同限不能证明二重极限存在；偏导存在不保证连续或可微；可微与偏导连续的单向推论；求导时固定哪些变量；方向需单位化；驻点不等于极值 | 变量替换化简偏导关系、二阶Taylor、退化驻点、约束正则性与Lagrange法、闭区域边界检查均列入覆盖核对；困难综合题用代表题保留核心方法 |

基础仍按“公式及条件 → 简单例子 → 怎样接入当前题型”组织，并补充：给定条件能推出什么、不能反推什么、缺条件时需补查什么。定义只在直接用来判别、求导或证明时展开。

特别核对一元/多元的可微关系，以及方向导数的单侧或双侧约定，避免不同定义的例子混用。第4章遇到依赖偏导的综合例题时，先给最少先修提示并标出第6章回访位置，保持原书次序。

## 4. 时间框架，待逐题估量后锁定

| 日期 | 暂定内容 | 时间如何使用 |
|---|---|---|
| 10月25—26日 | 第4章 | 例题与方法约30%—35%，独立习题约45%—50%，其余订正与旧章复习 |
| 10月27日 | 第5章 | 计算前先选向量和方程，课后独立练习至少与例题学习等时；原书全部题目保留分层入口 |
| 10月28—30日 | 第6章 | 概念关系和求导先打通，几何应用与极值分别检验；核心训练量决定是否需要调出机动时间 |
| 10月31日—11月4日 | 第7章预留 | 本轮不逐题整理；需保留区域判断、计算及积分定理的学习与练习时间 |
| 11月5—7日 | 第8章预留 | 本轮不逐题整理；保留判敛、幂级数与展开等方向的学习与练习时间 |
| 11月8日 | 机动与补弱 | 优先处理实际核心未过关内容 |
| 11月9—12日 | 整卷与复盘 | 优先未见真题；已见题分数单独说明，每卷留足订正时间 |
| 11月13日 | 轻量回顾 | 约3—4小时，查条件、方法和旧错，不补整章 |
| 11月14日 | 考试 | 具体安排按准考信息 |

2+1+3天是待核算的框架，不是已经完成逐题估时的承诺。按6小时配置主线，额外2小时用于巩固、挑战和补弱，不把所有储备题都压进日程。

每日先预留35—40分钟旧章复习：5分钟闭卷回忆、25—30分钟独立做题、5分钟记录。错题与关键方法按次日、第3天、第7天回访，熟练后转周抽查。每周一次60分钟混合检测替代当日普通复习，并从扩展练习调出差额，避免额外叠加工作量。

## 5. 交付顺序与确认点

1. **当前步骤：范围与筛选标准。** 本稿供确认，学习网页尚未改动。
2. **三章逐例筛选。** 按书序列题号、程度、方法、具体学习要求、替代/铺垫、页码和用时；核对真题难度参照。完成后沟通确认。
3. **三章课后习题筛选。** 全量清点与拆问，标K/J/T/R/Z，检查覆盖、重复和足够的独立题；仅在原书缺口确实存在时自编补题。完成后沟通确认。
4. **网页与计划落实。** 按确认题目制作4、5、6章HTML，接入母结构、题号搜索、基础索引及全站基础入口；沿用原题/答案分开和进度记录。新增基础服务三章，原有内容保留。按实算工作量修订10月25日起的计划，验证电脑与手机后同步GitHub。
