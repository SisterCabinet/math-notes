D1 / A · 特殊点：先查定义

导数定义、分段点与可微

核心

考试侧重 概念判断＋短计算

要掌握的知识

导数是差商极限：\(f\prime(a)=\lim_{h\to0}[f(a+h)-f(a)]/h\)。左右导数存在、有限且相等才可导；可导必连续，连续未必可导。一元函数可微等价于可导，\(dy=f\prime(x)dx\)，而 \(\Delta y=dy+o(\Delta x)\)。

进入这个母结构的信号

分段点、绝对值尖点、只给某一点导数、极限式含 f(a+h)−f(a)。第一步写出实际的 f(a)。

不能照搬的边界

不能把两侧公式的导数直接当作接点导数；先验证接点连续。变量代换若只覆盖一侧，不能推出双侧可导。

知识点对应的例题

原创铺垫题 · 建议 6 分钟

把连续条件与可导条件分开

设 \(f(x)=\begin{cases}e^x+a,&x\le0,\\1+bx+x^2,&x>0.\end{cases}\) 求使其在 0 处可导的 a,b，并写出该点微分。
展开思路与解答
  1. 连续要求 \(1+a=1\)，故 a=0。
  2. 左右差商极限分别为 1 与 b，故 b=1。
  3. \(f\prime(0)=1\)，所以 \(dy=dx\)。

a=0，b=1，dy=dx。

第17届非数 A · 二（2025） · 建议 15 分钟

与积分联动的真实难度

设 f 在实数轴上连续、在 0 处可导，且 \(f(x)=x^3+x^2\lim_{t\to0}f(t)/t-x\int_0^1f(t)dt\)。求 f。
展开思路与解答
  1. 代 x=0 得 f(0)=0。记 \(A=f\prime(0),B=\int_0^1f\)，则 \(f(x)=x^3+Ax^2-Bx\)。
  2. 再算 0 处差商得 A=−B；积分得 \(B=1/4+A/3-B/2\)。
  3. 解得 \(A=-3/22,B=3/22\)。

\(f(x)=x^3-\frac3{22}x^2-\frac3{22}x\)。

第17届 A 二直接把导数定义与积分常数联立；这是第2、3章共同的母结构。

过关标准：遇到接点会写两侧差商；看到极限常数会尝试把它命名后联立。

D2 / A · 特殊点：先查定义

振荡函数：连续、可导与导数连续

核心

考试侧重 概念边界＋估阶

要掌握的知识

对 \(x^\alpha\sin(x^\beta)\)（x>0，β<0），用“振幅→差商→求导后振幅”分层检查；右侧接 0 时，连续需 α>0，可导需 α>1，导数连续需 \(\alpha+\beta-1>0\)。完整多参数分情况不必反复刷，但这三层逻辑必须懂。

进入这个母结构的信号

振荡项有极限障碍，先用 |sin|≤1 估振幅，随后检查差商多除一个 x 的影响。

不能照搬的边界

f 可导并不代表 f′连续；“有界振荡”不等于有极限。临界指数须用子列检查。

知识点对应的例题

原创铺垫题 · 建议 7 分钟

可导却导数不连续

设 \(f(x)=x^2\sin(1/x)\)（x≠0），f(0)=0。判断在 0 处连续、可导及 f′连续性。
展开思路与解答
  1. \(|f(x)|\le x^2\)，故连续。
  2. \(f(x)/x=x\sin(1/x)\to0\)，故 f′(0)=0。
  3. 非零处 \(f\prime(x)=2x\sin(1/x)-\cos(1/x)\)，沿两组子列取不同极限。

连续且可导，f′(0)=0，但导数在 0 不连续。

过关标准：能用一个反例拆开“连续→可导→导数连续”的错误推理。

D3 / B · 多层表达式：先拆依赖

复合、反函数、对数求导与一阶微分

核心

考试侧重 计算为主

要掌握的知识

链式法则逐层乘；\((f^{-1})\prime(y)=1/f\prime(x)\) 要求 f′(x)≠0。对正值幂函数 y=u(x)^{v(x)}，先取对数：\(y\prime/y=v\prime\ln u+vu\prime/u\)。一阶微分形式不变：dy=f′(u)du；二阶微分不能照搬。

进入这个母结构的信号

指数、底数都含变量，或多层复合／反函数；先画出变量依赖，再决定是否取对数。

不能照搬的边界

取对数要有正值条件；反函数求导不能在原函数导数为零的点套公式。

知识点对应的例题

D4 / B · 多层表达式：先拆依赖

隐函数、参数方程、切线与法线

核心

考试侧重 计算＋条件核查

要掌握的知识

隐函数 F(x,y)=0 在 F_y≠0 处：\(y\prime=-F_x/F_y\)。参数式：\(dy/dx=y_t/x_t\)，\(d^2y/dx^2=(d/dt)(y_t/x_t)/x_t\)。切线先求点，再求斜率；斜率为 0 时法线是竖直线。

进入这个母结构的信号

y 没有显式表达式，或者 x,y 由同一个参数给定；对每个出现的 y 都带上 y′。

不能照搬的边界

分母为零时，要另查局部曲线；二阶参数导数不能直接写成 y″(t)/x″(t)。

知识点对应的例题

第10届初赛（2018）／教材例2.74 · 建议 8 分钟

参数中又藏着隐函数

曲线由 \(x=t+\cos t,\ e^y+ty+\sin t=1\) 确定，求 t=0 对应点处的切线。

  2. 隐式求导得 \((e^y+t)y_t+y+\cos t=0\)，故 y_t(0)=−1。

D5 / C · 高阶目标：先看消零因子

高阶导数：系数、Leibniz 与递推

核心

考试侧重 结构识别＋计算

要掌握的知识

若已知函数在展开点足够光滑，\(f(x)=\sum a_k(x-a)^k+o((x-a)^n)\) 可读出 \(f^{(n)}(a)=n!a_n\)。\((uv)^{(n)}=\sum_{k=0}^n\binom nk u^{(k)}v^{(n-k)}\)。遇 \((x-a)^n g(x)\)，在 a 点只有一项存活。有理函数先部分分式；复杂函数可先建立低阶恒等式，再求 n 阶得到递推。

进入这个母结构的信号

求很高阶在指定点的导数，尤其有高次零点／有理分式。先找局部系数，避免机械连求 n 次。

不能照搬的边界

读系数须有足够可导性；递推建立后不一定需要解通项，更不需要矩阵特征值推导。

知识点对应的例题

D6 / D · 存在性：先造同端值

Rolle、Lagrange、Cauchy 与反复使用

核心

考试侧重 思维为主

要掌握的知识

Rolle：闭区间连续、开区间可导、端值相等。Lagrange：\(f(b)-f(a)=f\prime(\xi)(b-a)\)。Cauchy 的稳妥形式：\([f(b)-f(a)]g\prime(\xi)=[g(b)-g(a)]f\prime(\xi)\)；写比值时另查分母。多个零点先对原函数 Rolle，再对导数 Rolle；用 f 减去弦线／低次多项式可以制造零点。

进入这个母结构的信号

要证“存在一点使导数等于某量”；把目标中的常数或线性项先积分回辅助函数。

不能照搬的边界

不能凭两个不同中值点写成同一点；对 f′再用 Rolle，要核查 f′在所选闭区间连续。

知识点对应的例题

原创铺垫题 · 建议 5 分钟

柯西中值定理的一步铺垫

设 f 在 [1,2] 连续、(1,2) 可导。证明存在 ξ∈(1,2)，使 \(f\prime(\xi)/(2\xi)=[f(2)-f(1)]/3\)。
展开思路与解答
  1. 取 g(x)=x²。g′=2x 不为零，且 g(2)−g(1)=3。
  2. 对 f,g 用 Cauchy 中值定理，得到目标比值。

所求 ξ 存在。

原创铺垫题 · 建议 5 分钟

反复 Rolle 的短模型

设 f 在 [0,1] 二阶连续可导，f(0)=f(1/2)=f(1)=0。证明存在 ξ∈(0,1)，f″(ξ)=0。
展开思路与解答
  1. 分别在两半区间用 Rolle，得 u∈(0,1/2)、v∈(1/2,1)，f′(u)=f′(v)=0。
  2. 对 f′在 [u,v] 再用 Rolle，得结论。

二阶导数在某个内点为零。

为何保留／练到什么程度

第2、12届初赛及教材例2.76、2.78体现中值定理组合；Cauchy 保留是因为方法通用，并非只由频率决定。

过关标准：能从目标反推辅助函数，并完整写出使用定理的三项条件。

D7 / D · 存在性：先造同端值

两个中值点：介值分点再分区间

核心

考试侧重 构造思维

要掌握的知识

出现 ξ≠η 时，优先找一个分点 c，把两点安置在不相交的开区间；先用介值定理确定 f(c) 与 c 的关系，再在 [a,c]、[c,b] 使用 Lagrange。不能在整个区间独立套两次定理来保证不同。

进入这个母结构的信号

目标中两个导数相乘、相加，或者显式要求两个点不相同。

不能照搬的边界

若 c 在端点，就失去两个非空区间；先证明 c 为内点。

知识点对应的例题

第12届初赛（2020）／教材例2.78 · 建议 15 分钟

真题：先找分点再乘两条斜率

设 f 在 [0,1] 连续、(0,1) 可导，f(0)=0，f(1)=1。证明存在不同 ξ,η∈(0,1)，使 \([1+f\prime(\xi)][1+f\prime(\eta)]=4\)。
展开思路与解答
  1. \(H(x)=f(x)+3x-2\)，H(0)=−2，H(1)=2，故存在 c∈(0,1)，f(c)=2−3c。
  2. 两半区间的 Lagrange 给出 \(f\prime(\xi)=(2-3c)/c\)、\(f\prime(\eta)=(3c-1)/(1-c)\)。
  3. 因此 \(1+f\prime(\xi)=2(1-c)/c\)，\(1+f\prime(\eta)=2c/(1-c)\)。两点属于不相交区间。

乘积为 4，且 ξ≠η。

D8 / D · 存在性：先造同端值

积分因子与导数介值性质

核心

考试侧重 识别结构＋证明

要掌握的知识

目标 f′+p(x)f=q(x)，先乘积分因子 \(\mu=e^{\int p}\)，有 \((\mu f)\prime=\mu(f\prime+pf)\)。有时还需先减去一个简单函数再用 Rolle。导数虽可不连续，但具有介值性质（Darboux）；没有 f′连续条件时，不可直接对 f′用连续函数介值定理。

进入这个母结构的信号

f 和 f′在结论中同时出现，像一阶线性微分方程；先尝试把目标合成一个导数。

不能照搬的边界

积分因子不是万能法，端值必须能被条件控制；Darboux 的证明可了解，但性质与适用条件要会。

知识点对应的例题

原创铺垫题 · 建议 6 分钟

把 f′−f 合成一个导数

设 f 在 [0,1] 连续、(0,1) 可导，f(0)=f(1)=0。证明存在 ξ∈(0,1)，f′(ξ)=f(ξ)。
展开思路与解答
  1. 取 \(F(x)=e^{-x}f(x)\)，F(0)=F(1)=0。
  2. Rolle 给出 \(F\prime(\xi)=e^{-\xi}[f\prime(\xi)-f(\xi)]=0\)。

所求 ξ 存在。

为何保留／练到什么程度

教材例2.86是初赛中的微分不等式；积分因子还能迁移到第4章微分方程。

过关标准：能看到 f′±f 就想到指数因子；知道导数介值与导数连续不是一回事。

D10 / F · 估计：留住受控余项

Taylor 余项与导数估计

核心

考试侧重 思维＋误差控制

要掌握的知识

算定点导数／局部极限时用 Peano 余项；证明一个区间上的误差界时用 Lagrange 余项：\(f(x+h)=f(x)+f\prime(x)h+f^{\prime\prime}(\xi)h^2/2\)。若只有 f′是 M-Lipschitz，可用积分得 \(|f(x+h)-f(x)-hf\prime(x)|\le Mh^2/2\)，不必假设 f″存在。

进入这个母结构的信号

给 |f″| 上界或 f′变化上界，要估 f′、函数值或误差。先保留 h，再用最合适的 h 优化。

不能照搬的边界

o(h²) 只能描述 h→0，不能替代全局 Mh²/2；Lipschitz 条件不能擅自改成“处处二阶可导”。

核心

考试侧重 公式计算＋概念边界

要掌握的知识

f″>0 表示曲线位于切线上方，f″<0 表示位于切线下方，避免“凹／凸”叫法差异。拐点要查凹凸变号。斜渐近线 y=ax+b 要同时算 \(a=\lim f(x)/x\)、\(b=\lim[f(x)-ax]\)。\(ds=\sqrt{1+(y\prime)^2}\,dx\)，\(\kappa=|y^{\prime\prime}|/[1+(y\prime)^2]^{3/2}\)，曲率半径 ρ=1/κ（κ≠0）。 参数曲线曲率 \(\kappa=|x\prime y^{\prime\prime}-y\prime x^{\prime\prime}|/(x\prime{}^2+y\prime{}^2)^{3/2}\)。曲率圆是沿主法线方向、半径为 ρ 的局部密切圆；中心坐标长计算可后置。

进入这个母结构的信号

图形性态、斜渐近线、弧长与曲率；先确认用 x 还是参数求导。

不能照搬的边界

f″=0 只给拐点候选；算出斜率 a 但 b 极限不存在就没有斜渐近线。曲率圆长计算可延后，曲率概念和公式保留。
